## Efeitos Procedurais (sem assets externos)

Os seguintes efeitos são 100% gerados via código (CSS + SVG + Framer Motion), sem assets externos:

- `SpellEffect` — anéis de magia procedurais (fire, ice, lightning, poison, holy, dark, levelup, buff, debuff)
- `LevelUpEffect` — burst de estrelas + anéis + label animado
- `DamageNumber` — números de dano flutuantes com tipagem por tipo (physical, magic, heal, critical, miss, poison, fire, ice)
- `ScreenShake` — shake procedural via spring physics
- `FloatingIcon` / `PulseGlow` / `SelectionRing` — animações idle CSS
- `IdleBreathing` / `HitFlash` — estado de personagem via Framer Motion
- `StatusBar` — barras HP/MP/XP/Rage/Shield animadas com shimmer
- Shimmer sweep nas cartas épicas/lendárias/míticas/divinas — animação CSS pura
